*Почему вычисление ДНК не является безопасной случайностью?*
Все входные данные (msg.sender и name) публичны и известны заранее. Любой пользователь может на своем компьютере заранее просчитать хэш keccak256 и перебирать разные имена до тех пор, пока не получится ДНК, полностью исключая элемент честной случайности.
